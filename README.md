### How to's
CD to desire folder

#### web-server
Simple web app to add and calculate students notes, run: `go run web_server.go`  
In the browser, open  **[http://localhost:9999/](http://localhost:9999/)**

### simple-chat-simulation
Local chat simulation whichs supports sending messages & files. First, run the **server** wich keeps track of everything `go run .\server.go`  
Then, run as many **clients** as you want with: `go run .\client.go`. Every terminal is a client
